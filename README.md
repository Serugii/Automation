# Лабораторна робота № 1. Розгортання середовища автоматизації тестування

**Виконавець:** Прізвище Ім’я
**Група:** XX-00
**Варіант:** 3 — перетворення секунд на рядок формату «гг:хх:сс»; відхилення від’ємних значень

## Індивідуальне завдання (варіант 3)

Функція `secondsToTime(totalSeconds: number): string` у `src/time.ts`
перетворює секунди на рядок `гг:хх:сс`:

| Вхід     | Результат   |
| -------- | ----------- |
| `0`      | `00:00:00`  |
| `3661`   | `01:01:01`  |
| `86399`  | `23:59:59`  |
| `360000` | `100:00:00` |

Некоректні дані відхиляються винятком:

| Вхід                       | Помилка            |
| -------------------------- | ------------------ |
| від’ємне число (`-1`)      | `NEGATIVE_SECONDS` |
| `NaN`, `Infinity`, дробове | `INVALID_SECONDS`  |

## Пороги покриття

Задані у `vitest.config.ts`: рядки ≥ 80 %, гілки ≥ 80 %, функції = 100 %.
Поточний результат: 100 % за всіма показниками.
